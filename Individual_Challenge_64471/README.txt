The pm25_traffic_visualizations.ipynb contains the dashboard with the time series of the PM2.5 data and other visualizations on PM2.5 and traffic.
The forest_dashboard.py script generates the dashboard for the World Forest Cover Dashboard
The weather_dashboard.py script generates the dashboard for the Global Weather Dashboard

There are three videos in this folder, that highlight the visualizations and the insights of the three dashboards, running on localhost.

There might be issues with the display of the dashboard in the Jupyter Notebook, the functionalities are presented in its respective video.

The individual challenge's report is the PDF file in the folder.
